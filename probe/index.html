AngouriMath under WebAssembly: what loading it costs

Three copies of one tiny .NET 10 WebAssembly app, differing only in the AngouriMath kernel. Each loads the runtime, calls an exported function twice, and shows how long each step took and how many bytes came over the network.

  • baseline: no AngouriMath, the bare runtime
  • trimmed: the kernel trimmed to what parsing and Simplify reach
  • whole: the kernel kept whole

The first visit downloads everything; a reload takes most files from the browser's cache. Each page has a Run again cold link that downloads and compiles everything again, which is the number that matters for a first-time visitor, on a phone above all.

The measurements these reproduce, and the question they bear on: AngouriMath#2296 and AngouriMath#1692. Built from AngouriMath master aef5535, .NET SDK 10.0.402, Release, TrimMode=full, no AOT.

The AngouriMath Live demos run the same way.
